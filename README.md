# 地方競馬AI予想帳

地方競馬向けの予想・保存・結果入力・回顧・学習ツールです。

## Ver.2 地方競馬専用ロジック

- 会場 × 距離を予想の基本条件として使用
- 馬場はダート固定、クラス入力は廃止
- レース番号は1R〜12Rのプルダウン
- タイム指数を最重要視
  - 初期配分: 全体最高15 / 近5走50 / 距離15 / コース20
  - 近5走は今回と同じ会場 × 同じ距離を最優先
  - 同場近距離 → 他場同距離 → 他場近距離の順で評価を弱める
  - 直近ほど重く、安定して指数を出している馬を加点
- 中央からの転入馬は別処理
  - 中央ダート同距離・近距離の能力を残す
  - 地方初戦は適応不確定分だけ軽く割引
  - 中央指数が地方メンバーより明確に高い場合は能力差を評価
- 騎手を地方競馬向けに強化
  - 保存済み結果から「騎手 × 会場 × 距離」を自動集計
  - 5戦未満は補正なし、5〜9戦は弱く、10〜19戦は中程度、20戦以上で本格反映
  - 人気薄の好走・上位人気の取りこぼしも補助評価
- 会場 × 距離の脚質傾向も保存結果から学習（脚質データがある場合のみ）
- 人気とAI順位のズレから穴候補・危険人気を判定
- 厩舎コメント・調教は浦和/船橋/大井/川崎/門別のみ任意入力
  - 空欄でも減点なし
  - その他の会場では入力欄自体を隠し、タイム指数・展開・騎手だけで予想可能

## 標準入力テンプレ

1. 出走表
2. タイム指数（標準）
3. タイム指数（近5走）
4. 展開・タイム予測
5. 厩舎コメント（南関・門別のみ任意）
6. 調教（南関・門別のみ任意）

「テキストを一括反映」を押すと、指数計算から ◎○▲△☆ の自動印まで実行されます。

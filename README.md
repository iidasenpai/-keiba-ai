# 地方競馬AI予想帳

地方競馬15会場（帯広・門別・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀）に対応した、スマホ向けの予想・保存・結果回顧・学習ツールです。

## 主な機能
- 出走表／タイム指数（標準）／タイム指数（近5走）／展開予測／厩舎コメント／調教評価の一括入力
- 人気・オッズを保存して予想時の市場補正に利用（補正は弱め）
- レースを先に保存し、終了後に結果だけ入力して自動回顧・学習
- 結果データから自動学習・全再学習
- 会場・距離別の成績確認
- JSON全データバックアップ／復元
- スマホ向けコピー・貼り付け、テキスト一括クリア
- GitHub Pagesで動作

## 開発
`npm install` → `npm run dev` / `npm run build`

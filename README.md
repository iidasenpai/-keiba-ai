# 地方競馬AI予想帳 Ver3.0

既存の四軸指数ツールを、地方競馬15場対応へ拡張した試作版です。

## 追加機能

- 門別・帯広・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀に対応
- 競馬場ごとに「最高値・近走・距離・コース」の重みを自動調整
- 競馬場ごとの前残り／差し補正
- 距離、クラス・条件の保存
- レース結果と回顧メモを予想データと一緒に保存・書き出し

## 起動

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

会場別バイアスは `src/App.tsx` の `TRACK_BIAS` で調整できます。現段階は検証用の初期値で、結果を蓄積しながら更新する前提です。

# NAR-AI v12.1 — iPhone / iPad入力支援

v12へSafari取得ファイルの一括取込を追加した差し替え版です。公開・デプロイはまだ行っていません。

## 入っているもの

- src/ の6ファイル：既存プロジェクトの同じ場所へ配置。v12からは4ファイルを更新し、sourceImport.tsとSourceImportPanel.tsxを追加。
- iphone/collect-safari.js：同じサイトのページをまとめて読むショートカット用スクリプト。
- iphone/collect-current-page.js：まとめ取りが制限される場合の1ページ取得用スクリプト。

storage.ts、main.tsx、package.jsonは変更不要。新しいnpm依存はありません。v12以前の全データ保存を手元に残した上で更新してください。

## 毎回の操作（まとめ取りが動く場合）

1. ログイン済みのSafariでnetkeibaの地方出馬表を開く。内容が揃ってから共有→下記のショートカットを実行し、netkeiba.jsonとして保存。
2. 同じレースの競馬ブック「調教」を開き、共有→同じショートカットを実行し、book.jsonとして保存。
3. 予想アプリの「Safariで取得したファイルを一括取込」で2ファイルを選ぶ。iPhoneで1個ずつ選んでも追加できます。
4. 開催情報・頭数・取得済み／未取得を確認し、「6ページを入力へ反映」を押す。各馬の値を確認してから予測を保存します。

レースごとにnetkeibaと競馬ブックの対象ページを開いてください。両社のIDを推測変換しません。

## 初回だけ：ショートカット作成

これは署名済みのインストール用.shortcutファイルではありません。iPhone側で以下の設定が必要です。

1. ショートカットアプリで新規作成し、名前を「競馬データ取得」にする。
2. 詳細の「共有シートに表示」をオン。受け取る種類を「SafariのWebページ」にする。
3. 「WebページでJavaScriptを実行」アクションを追加。入力を「ショートカットの入力」にし、初期コードを全消去してcollect-safari.jsの全文を貼る。
4. 「名前を設定」アクションを追加。入力をJavaScriptの結果、名前をnar-source.jsonにする。
5. 「ファイルを保存」アクションを追加。入力は名前を設定した結果。「保存先を尋ねる」をオン。
6. 実行時はSafariの共有メニューから起動する。netkeibaと競馬ブックのファイルは別名で保存し、片方を上書きしない。

Appleの案内に従い、必要なら「設定」→「アプリ」→「ショートカット」→「詳細」で「スクリプトの実行を許可」を設定してください。名称・場所はOSで異なります。実行時にサイトごとの確認が出る場合があります。
公式手順：https://support.apple.com/ja-jp/guide/shortcuts/apdb71a01d93/ios
仕様・時間制限：https://support.apple.com/ja-jp/guide/shortcuts/apd218e2187d/ios

## 取得するもの

netkeiba：出馬表、出馬表詳細、標準指数、近5走指数。出馬表から読めるAIペースの文字列・見解も保持します。画面を切り替えないと出ないAIの図・位置座標・騎手補正別タブの全情報の取込には対応していません。各馬のAI予測タイムが未取得なら生成しません。
競馬ブック：調教短評・時計、厩舎コメント。調教評価は既存アプリの規則で計算し、サイトの公式評価と区別して扱ってください。

近5走は年間最高の列を除外し、過去5つの枠を保持。欠走の「-」を0点にせず、負数の指数も保持します。標準指数の「未」は空欄として扱います。

全ファイルを読む段階で開催日・会場・R・距離・発走時刻（双方にある場合）と全馬の馬番・馬名を照合します。不一致・重複・列数変更は反映を止めます。取得の日時・URLを入力の根拠として残しますが、予測を事前に保存した時刻には使いません。

入力への反映では、現在の未保存入力を新しいレースで置き換えます。保存済み予測・結果は変更しません。データが部分的な場合はそのことを表示し、未取得部分を空欄にして取り込めます。元ページに不足や取消情報の不整合がある場合は、反映前に確認してください。

## 制限と検証状況

提供された6つのURLはブラウザで実際に開き、当該レースの本文・表構造を確認しました。会員として読めない内容を取得する処理はありません。認証情報を読み出したり、パスワードやCookieを別サービスへ送信する処理もありません。

まとめ取得は同じサイトの別ページをフレーム内で開きます。サイト側のフレーム制限、Safariの共有アクションの時間制限、読込遅延などで取得できないことがあります。失敗はファイルのerrorsとアプリの注意表示に残します。iPhone実機・実サイト上でのショートカット実行は未検証です。現時点で「必ず2操作で全取得」とは保証できません。

まとめ取りが失敗する場合は、ショートカットのコードをcollect-current-page.jsに替え、6ページそれぞれで共有→保存し、6ファイルを同時に選んでください。同じ種類を重複取得した場合は、アプリで古いファイルを外してから反映します。

検証：提供ページの表構造に合わせたテスト用ページで、netkeiba4ページ・競馬ブック2ページの収集、6ソース照合、負数・欠走・年間最高の除外、形式不正の拒否を確認。アプリ上で入力反映・再反映と既存513レースの保持を確認。従来の回帰検証23項目と保存・復元等の画面操作10項目も実行。iPhone実機での最終確認が残っています。

実サイトの文言や列構造が変わった場合は、取得・取込処理の更新が必要です。

# NAR-AI v12.3 — 結果ファイルの一括反映・回顧・学習

GitHubの既存srcへ、このZIPのsrc内8ファイルを追加・上書きしてください。v12.2の一括予想読込も含みます。npm追加やSafariの設定は不要です。

## 使い方

1. 予想は従来どおり、発走前にアプリへ保存します。
2. ChatGPTから受け取る結果JSONをiPhoneの「ファイル」に保存します。
3. アプリの「結果ファイルを一括反映・学習」でそのJSONを選びます。
4. 確定・未確定件数、反映可能・スキップ理由を確認し、「結果を反映して回顧・学習」を押します。

全頭の着順・取消等の出走状態・回顧を反映し、学習ONなら保存結果から学習値を再計算します。学習OFFなら結果・回顧のみを反映します。読み込みと反映の操作は必要です。Webサイトへ常時接続する機能ではなく、私が取得したファイルを読み込む方式です。

途中の結果ファイルを先に読み込めます。未確定・取得不可は理由を表示し、後のファイルで確定分を追加できます。同じ結果を再読込しても二重学習しません。

## 保持・照合

固定予想の順位・点数・保存時刻は書き換えません。予想計算の重みや採点部分は変更していません。既存v12.2予測との比較・学習を継続するため、予想エンジン識別子もv12.2を引き継ぎます。

日付・会場・R・距離・元レースID・全馬の馬番と馬名を照合します。固定済み予測がない場合は結果から事前予測を作らず、スキップします。複数の再予測が同じレースに対応する場合は、照合できる各保存予測へ同じ結果を反映します。

すでに反映した結果と異なる場合は自動上書きせず、手動確認が必要な理由を表示します。手動で上位3着だけ登録済みの場合、同じ上位3着で既存の確定着順に矛盾がなければ全頭の結果を補足できます。

4着以下の同着は同じ着順として保持します。1〜3着の同着は旧形式の1着-2着-3着と両立しないため、自動反映せず確認待ちにします。

保存済み結果に不整合があるレースや、別レースの可能性があるデータは自動修復しません。結果保存と学習状態はまとめて保存し、保存失敗時は画面の学習状態を更新しません。

## 今回の付随修正

結果で判明した取消・除外を、学習に使う結果表示にも反映します。固定予測そのものは保持します。馬場状態が未取得の入力は「良」に補完せず「未確認」と表示します。

## 検証

全頭結果・取消・再読込の冪等性、別馬・別日・未確定・矛盾結果の拒否、同着処理を検証。513件の既存データを含む画面テストで、一括反映・回顧・学習、固定予測と元513件の保持、再読込・保存復元を確認しました。学習OFFも確認しています。従来の回帰検証23項目も通過。iPhone実機での操作は未検証です。

結果ファイルの形式：format=nar-result-batch、version=1、raceDate、createdAt、expectedTotal、races、errors。各確定レースには開催情報・参照URL・取得日時・全頭rowsを含めます。確定件数と未確定／取得不可件数の合計を対象件数と一致させます。
